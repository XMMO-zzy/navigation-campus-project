## 3. 设计系统基线

| 项 | 规范 |
|---|---|
| 主色 | 教育蓝（主操作）＋ 信任绿（确认类）＋ 警示红（涨跌/危险提示，遵循中国股市红涨语境不涉及） |
| 字体 | 系统默认；正文 28rpx / 辅助 24rpx；深色模式双套色板（对齐 IDE 深色审美） |
| 组件 | WeUI 为底，自定义：信息流卡片、状态时间线、待办条目、骨架屏、空态（配引导文案与行动按钮） |
| 图标 | 单色线性图标库，业务四域各一识别色（二手/搭子/活动/竞赛） |
| 卡片规范 | 发布者信息 + 正文 + 互动数据 + 操作栏四段式（《04》动态卡片结构），跨六类卡片视觉统一 |

## 4. 关键体验决策

1. **待办优先**：首页"重要消息"区在视觉层级上高于推荐流（调研验证的刚需，《10》§6.3 要点 1）；
2. **状态透明**：订单时间线、报名状态、审核结果全部可视化（《01》交互共性 5）；
3. **安全可视**：联系方式解锁前展示锁形提示与原因文案（配合 G 的脱敏策略，降低用户困惑）；
4. **空态引导**：每个列表空态都带"去发布/去逛逛"行动点（冷启动 R-06 的体验侧配合）；
5. **防诈提示常驻**：交易详情页固定安全提示条（《17》§5 文案，J 提供法务措辞）。

## 5. 走查机制（F4）

- 每里程碑演示版发布后 2 个工作日内完成还原走查，输出差距清单（截图对照）落禅道（S3 级默认）；
- 走查清单：间距/字重/色值/圆角/暗色适配/长文案截断/极端数据（20 字昵称、9 图、超长标题）；
- 深色模式专项：《15》TC-M7-05，四 Tab 全走查（M3）。
