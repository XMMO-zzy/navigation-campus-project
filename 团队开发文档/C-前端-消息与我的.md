## 2. 实现要点

### 2.1 消息中心

- 列表 `GET /messages?box=&biz=`；角标聚合 `GET /messages/badge` 驱动底部 Tab；
- 点击通知按 `link_type/link_id` 路由到业务详情；已读多端同步（5s 内，TC-M3-08）；
- **免打扰**：本地夜间不弹层不响，消息静默入库（与 F 的服务端频控互补）。

### 2.2 申请中心（组队协作，核心体验）

- `direction` 三个视图：收到的申请（展示申请人技能/简介/学校/理由）→ 操作 agree/reject/ask（补充询问）；我的申请（四态 + 撤回）；收到的邀请（agree/reject/consider）；
- 状态流转用统一标签组件渲染（颜色映射 status 0~4）。

### 2.3 TIM 集成

- 登录后 `GET /im/sign` 换 userSig 初始化 TIM；会话列表由 SDK 提供，消息页做统一皮肤；
- **业务卡片消息**：自定义消息体 `{linkType, linkId, title}`，渲染为可点击卡片跳转（与 B 的详情页路由对齐）；
- 队伍群聊：入队事件后（`team_notice`）SDK 侧建群/入群由后端 REST 完成，前端只消费群消息与公告。

### 2.4 我的页

- 资料卡（基础/能力/数据概览）+ 认证状态角标；右上角设置入口，**安全风险提示红点**（账号安全通知联动）；
- 记录区：商品订单（买家/卖家双视角 + 状态时间线）、活动记录（进行中/历史）、竞赛参赛记录与成果展示（P2）；
- 管理区：组队管理、内容管理（复用 B 的列表组件）、认证页；
- 设置中心：账号（手机/邮箱脱敏展示、改密、登录设备、注销流程含冷静期文案）、消息通知六类开关、隐私（可见范围/联系权限/黑名单/个性化推荐开关）、通用（缓存/字体/深色/语言占位）、帮助与反馈。
