## 3. 关键设计

### 3.1 登录与令牌

- JWT：accessToken 2h + refreshToken 7d；Redis 白名单存 jti，支持"退出其他设备"（TC-M1-07）；
- 微信登录失败兜底：code2session 超时重试 1 次，仍失败 50001（TC 前端引导重试）；
- 频控：登录 10 次/分/IP+openID（Redis 令牌桶）。

### 3.2 权限模型实现（《11》§3.1）

```java
@RequireRole(VERIFIED)   // 发布活动/竞赛
public Result<...> createActivity(...) {}
// HandlerInterceptor：无 Token 写接口 40001（BS-01）
// PermissionChecker：user_type 判定 40003（BS-02）
// 认证审核通过事件 → user_type=2 + 权重 boost 1.5 + 通知
```

**铁律**：任何写接口不得只依赖前端隐藏；越权矩阵（《15》ST-01）为发布门禁。

### 3.3 内容审核流水线（《11》§3.6）

```
文本：DFA 一级词 → 40008；二级词 → status=0 待审（人工队列）
图片：数据万象同步审核 → 拦截则 file_object.audit_status=2 并阻断发布
举报：工单 SLA 24h（handled_at - created_at 统计）→ 处罚（下架/禁言/封禁）
      → 通知双方 + audit_log；申诉 → 二审改判恢复（TC-M7-02/03）
```

### 3.4 注销与数据安全（《18》§4）

冷静期 15 天内可撤销；到期任务物理删除 real_name/student_no/手机号（AES 密文列），内容行匿名化（nickname→"已注销用户"），审计记录保留。
