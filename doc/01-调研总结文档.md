## 二、共性功能梳理

### 1. 登录与认证
- **轻量化登录是标配**：微信授权一键登录（openID + 头像昵称），几乎无独立注册流程，"即用即走"。
- **学号/.edu 邮箱实名认证**：用于区分"普通用户"与"校内认证用户"，从源头过滤校外人员，是信任体系的基石。
- **分级认证**：部分平台叠加人脸识别（搭子类）、组织者认证（活动类），认证层级对应权限层级。

### 2. 信息聚合与分发
- **解决"信息碎片化"是所有产品的共同出发点**：把散落在 QQ 群、微信群、贴吧的交易/竞赛/活动信息集中化、结构化。
- **分类 + 多维筛选**：商品按品类/成色/价格区间；竞赛按学科/级别/主办单位；活动按类型/时间/学分。
- **推荐机制**：基于兴趣标签、LBS 同校、浏览/收藏行为的个性化推荐（到梦空间、搭子类做得最深）。

### 3. 内容发布
- **分步向导式发布**：选图 → 填信息 → 预览提交，降低发布门槛。
- **发布审核**：先审后发或敏感词自动过滤，是内容治理的底线配置。
- **场景化模板**：打包出售（毕业季）、求购（精准推送）、组局（时间/人数/费用 AA）。

### 4. 消息与触达
- **站内消息中心 + 微信服务通知（模板消息）双通道**，关键节点（报名截止、订单状态、匹配成功）强提醒。
- **消息角标**提升打开率。
- 自动化系统消息：面交确认提醒、审核结果、活动变更等。

### 5. 信任与治理体系
- **双向评价 + 信用分**：初始分制（如 100 分），违规扣分，低于阈值限制功能（如禁止发布）。
- **举报仲裁**：证据上传 → 管理员审核 → 处罚（下架/禁言/封禁）。
- **黑名单与降权**：低信用用户降低曝光。

### 6. 个人中心
- 订单/报名/收藏/发布记录四件套；
- 设置中心：账号安全、隐私、通知、帮助反馈、清除缓存；
- 成长记录沉淀：第二课堂成绩单（到梦空间）、参赛履历（竞赛类）。

## 三、各赛道亮点功能

### 3.1 二手交易
- **面交双向确认机制**：任一方发起需对方确认，双方同时发起直接完成，防止单方面"已收货"扯皮。
- **担保交易/资金托管**：买家确认后资金才结算给卖家（校淘），规避跑路与货不对板。
- **求购反向推送**：发布求购后系统自动推送给发布过相关商品的用户，促成高效匹配。
- **付款后才可查看联系方式**：防骚扰。
- **季节性专场**：教材教辅 / 新生好物 / 毕业清仓 / 公益捐赠四大板块。
- **待付款订单超时自动取消**（30 分钟），杜绝"占坑"。
- 智能提示：新手引导发布（3 步骤向导 + 图片数量/大小校验）。

### 3.2 找搭子
- **搭子类型细分**：学习（考研/自习/图书馆打卡）、运动、娱乐、旅行、饭搭子、技能搭子，标签化运营。
- **LBS + 兴趣标签匹配**：优先推荐同校/同城，匹配度百分比展示。
- **组局管理**：设时间/地点/人数上限/费用方式（AA/请客），确认参与后解锁联系方式，支持活动群聊。
- **女性专属模式**：女生可筛选仅看女性搭子——安全设计的差异化亮点。
- **组队打卡互相监督**（如"一周自习 3 次"）、AA 账单分摊，减少金钱纠纷。
- **隐私分级展示**：非好友不显示距离/活跃时间；动态可设"仅搭子可见"。

### 3.3 活动与竞赛
- **关键时间节点智能提醒**：报名截止、初赛、答辩自动推送——调研中被验证的最高频需求。
- **多级报名流程**：基础信息 → 参赛信息 → 资料上传 → 确认提交，含资格校验与重复报名拦截。
- **签到防代签**：扫码 + 位置校验，记录真实参与学时。
- **报名统计与导出**：按竞赛统计人数，名单导出 Excel，供组织者使用。
- **经验沉淀**：往届获奖者备赛心得、作品展示形成知识库，是竞赛类的内容护城河。

### 3.4 综合校园平台（超级课程表 / 到梦空间）
- **以高频刚需为锚点**（课表/学分）带动低频功能（交易/社交）。
- **本校为天然社交边界**：以学校为单位构建圈子，信任感强、内容噪音低。
- **成长档案**：把参与记录转化为可展示资产（第二课堂成绩单、能力雷达图），提升粘性与长期价值。
- **桌面级轻触达**：服务卡片/日程表，无需打开 APP 即可获取关键信息。

## 四、交互设计共性

1. **底部四 Tab 导航**：首页 / 动态（圈子）/ 消息 / 我的，与本项目规划一致，是校园类产品的成熟范式。
2. **顶部分类页签**：动态/信息流页普遍采用顶部页签（推荐/关注/分类频道），配合下拉刷新、上拉加载。
3. **瀑布流 + 双列卡片**：商品、动态信息流的主流呈现方式。
4. **搜索历史与快捷清除**：搜索框保留历史记录、支持单条删除与一键清空，所有成熟产品均有此设计。
5. **状态清晰化**：订单时间线（已下单→待面交→已完成→已评价）、报名状态（待审核/通过/驳回/取消）全程可视化。
6. **空状态与加载态**：分页加载防白屏、骨架屏、空状态引导发布。
7. **分享传播**：详情页一键分享微信好友/朋友圈，自定义分享卡片，带追踪参数。

## 五、可借鉴要点汇总（供本项目直接取用）

1. 微信/手机号一键登录 + 学号认证分级权限（游客/普通/认证）。
2. 商品发布走 3 步向导；动态/竞赛/活动发布前内容审核（敏感词 + 人工复审）。
3. 面交双向确认 + 信用分 + 举报仲裁，构成交易信任三角。
4. 搭子匹配用"标签 + 同校"起步即可，匹配度百分比是低成本高感知的体验点。
5. 竞赛/活动的"截止日期提醒"是刚需中的刚需，务必做成自动化系统消息。
6. 信息流采用混合卡片（动态/商品/活动/竞赛/个人/校园），顶部分页导航。
7. 搜索历史本地存储 + 单条删除 + 清空；草稿自动保存防丢失。
8. 消息中心分类收纳（互动/系统/交易/匹配），配合微信模板消息兜底触达。
9. 管理侧预留：数据看板、内容审核、举报工单、封禁管理、审计日志。
10. 以"浏览 + 收藏 + 专业"构建冷启动推荐：专业偏好做初始画像，行为数据做实时修正。
