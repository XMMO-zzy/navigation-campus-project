# 通航校园APP

> 面向高校（通航类院校）的校园综合服务小程序：**二手交易 · 找搭子 · 活动 · 竞赛** 四位一体。
> 首发微信小程序，单校试点，以"逛 → 发 → 联"闭环为主干，以信任与治理体系为底座。

- **版本**：v1.0 ｜ **日期**：2026-09-29
- **结构基线**：《04-思维导图（重构版）》（402 节点架构，源自 `通航校园APP架构设计.xmind`）
- **需求基线**：《10-需求文档》｜ **计划基线**：《14-开发计划》（16 周 / 10 人团队，M0~M4 里程碑）

## 技术栈

| 端 | 技术 |
|---|---|
| 前端 | 微信小程序原生框架 + WeUI，分包加载，腾讯云 IM SDK |
| 后端 | Java 17 · Spring Boot 3.2 · MyBatis-Plus · Redis 7 |
| 数据 | MySQL 8.0（30 张表，见《12-数据库设计》）· 腾讯云 COS + 数据万象审核 |
| 基础设施 | Nginx（HTTPS）· Prometheus + Grafana · 每日全量备份 + binlog |

## 快速开始（开发者）

```bash
# 后端
cd campus-server && mvn spring-boot:run -Dspring-boot.run.profiles=dev
# 前端：微信开发者工具导入 campus-miniapp，填入 AppID，指向本地后端 http://localhost:8080
# 接口契约：Apifox 导入《13-API接口文档》结构
```
