## 1. 快速上手（3 分钟）

```text
① 打开小程序 —— 不登录也能逛（游客模式）
② 想发布/收藏/报名？—— 底部「我的」→ 微信一键授权登录
③ 想办活动/办竞赛？——「我的」→ 学号认证，审核通过后解锁
④ 首页往下拉 —— 「重要消息」会提醒你 7 天内截止的活动、竞赛和商品
```

**页面地图**（对应《04-思维导图》主界面四 Tab）：

| Tab | 干什么 | 一句话口诀 |
|---|---|---|
| 首页 | 搜索、四宫格快捷服务、待办、推荐 | **"找"** —— 找东西、不错过 |
| 动态 | 校园信息流，刷帖、发帖、看讲座/比赛 | **"聊"** —— 看热闹、说两句 |
| 消息 | 通知、申请、私聊、组队 | **"办"** —— 处理事、联系人 |
| 我的 | 资料、订单、记录、设置 | **"管"** —— 我的资产我做主 |

## 2. 首页：找东西、不错过

- **顶部搜索**：可搜动态、帖子、重要消息、校园话题。你的搜索历史只有自己可见，可以单条删除，或一键清空（会再确认一次）。搜索框下方的"热门搜索"是近期大家都在看的内容。
- **消息入口**：右上角有红点时表示有未读，点进去直接跳到那条未读消息。
- **快捷服务四宫格**：
  - **二手**：逛两栏瀑布流的闲置商品；"我的商品/关注/订单"都在这进去。
  - **搭子**：按爱好筛选（学习/运动/娱乐/饭搭子…），找同校搭子。
  - **活动**：学校、组织、个人发布的活动，可申请参加。
  - **竞赛**：找竞赛 + **竞赛日程**——用日历看报名、初赛、决赛和截止日期，收藏的竞赛有变化会提醒你。
- **重要消息（待办区）**：
  - *即将截止*：7 天内截止的活动、帖子、商品、搭子和竞赛；
  - *报名开始*：已开放报名但你还没报的活动/竞赛；
  - *协作待办*：等你处理的申请、报名、邀请，以及待完善的资料。
- **内容推荐**：根据你的专业、浏览和收藏越用越懂你；不想被"懂"？「我的 → 设置 → 隐私 → 个性化推荐」可关闭。

## 3. 动态：校园新鲜事

- **顶部页签**：*推荐*（优先展示还能报名/申请的内容）｜*关注*（只看你关注的人/组织/队伍）｜*活动与竞赛*（详情齐全：主题、时间、地点、联系人、要求）｜*校园*（二手、搭子、社团、游戏等大杂烩）。
- **卡片操作**：点赞 ❤、评论 💬、收藏 ⭐、分享 ↗；看到不舒服的内容可以点 **举报** 或 **不感兴趣**（后者会减少同类推荐）。
- **发布动态**：文字 + 多图（可拖动排序）、绑定话题（商品/找搭子/竞赛/活动/学校/技能/校园）；发布前可设置**谁能看**（公开/仅关注/私密）和**谁能评论**。写到一半退出不丢——下次进来会提示恢复**草稿**。
- **信息流里能看到**：图文动态、二手商品（带价格成色）、搭子帖、个人经验分享、学习打卡、组队需求、竞赛获奖/备赛/复盘、讲座与调研信息。

## 4. 消息：处理事、联系TA

- **顶部**：全部 / 未读，及活动、竞赛、商品、搭子、系统五类入口；支持**全部已读**。
- **申请中心（组队协作）**：
  - *收到的申请*：想加入你队伍的人，资料里有技能、简介、学校和申请理由 → 同意 / 拒绝 / 追问补充；
  - *我的申请*：待处理 / 已通过 / 已拒绝 / 已撤回，一目了然；
  - *收到的邀请*：别人拉你入队，可同意 / 拒绝 / 考虑。
- **私聊与队伍群聊**：私聊支持发文字、图片、文件，还能把活动/竞赛/商品**卡片**直接发给对方；入队后自动进入队伍群聊，有公告和重要消息。
- **提醒**：报名开始、即将截止（精确到剩余时间）、材料提交、规则变化——都会自动推送，重要的事我们替你盯着。

## 5. 二手交易：从下单到面交（核心流程）

```text
看中商品 → 点"我想要"下单 → 卖家确认 → 双方可见联系方式 → 约时间地点面交
→ 付款 → 双方各自点「确认面交」→ 订单完成 → 互相评价
```

**为什么要"双向确认"？** 只有你们两个人都点了确认，订单才算完成，避免"他说给过钱了/他说给过货了"的扯皮。只有一方确认时订单会停在"待对方确认"，72 小时没人动会自动关闭。

**安全提示**：
- 付款前**请勿脱离平台私聊转账**——你看到的联系方式在卖家确认后才开放，就是为了防止骚扰和场外诈骗；
- 面交选择白天、人多的校内地点；
- 商品描述与实物不符，请在订单完成前**拒绝确认**并在订单页发起举报；
- 首版平台只做**信息撮合**，不代收任何资金（详见用户协议）。

## 6. 找搭子

筛选爱好标签找到同校搭子 → 看对方的性别、爱好、年龄、性格介绍 → 申请加入 → 对方同意后解锁联系方式。女生可开启**女性专属模式**，只看女性搭子。匹配成功的会进"我滴过的"列表。

## 7. 活动与竞赛

- **参加**：浏览报名 → 报名状态可在「消息」跟踪（待审核/通过/拒绝）；截止前系统自动提醒。
- **组队参赛**：发布组队需求或在消息页创建队伍，招人、审核、建群一站完成。
- **办活动/竞赛**（需学号认证）：设置报名起止、人数上限、是否需要审核报名；报名者资料由你审核，开始前 24h 未响应会被系统自动降权，请及时处理。
- **成果沉淀**：比赛结束在「我的 → 参赛记录」提交获奖信息与作品资料，它们会出现在你的主页，成为你的校园履历。

## 8. 我的

- **主页**：头像/昵称/学校、专业/技能/爱好/性格、参与与发帖数据；点击编辑资料。
- **记录**：商品订单、活动记录（进行中/历史）、竞赛参赛记录与成果展示。
- **管理**：组队管理（我的申请/队伍/招募/邀请）、内容管理（动态/帖子/评论/收藏）。
- **认证**：学号认证状态四态（未认证/认证中/已认证/未通过），未通过会展示原因，可重新提交。我们仅用于身份识别，**不会**对接学信网或向他人展示你的学号。
- **设置中心**：账号（手机/邮箱/密码/登录设备/注销）、消息通知开关（可细到组队/活动/商品/搭子/互动每一类）、隐私（谁能私聊我、资料可见范围、黑名单、个性化推荐开关）、通用（缓存/字体/深色模式）、帮助与反馈。

## 9. 常见问题（FAQ）

| 问题 | 答案 |
|---|---|
| 不登录能用吗？ | 能逛能看，任何"写"操作会提示你登录（游客模式）。 |
| 我的手机号会被别人看到吗？ | 不会。所有联系方式仅在你和对方建立联系（订单确认/匹配成功/组队）后互相可见，且他人主页不展示。 |
| 卖家不确认订单怎么办？ | 卖家 30 分钟未响应会自动关闭订单，商品重新上架。 |
| 东西有质量问题怎么办？ | 面交当场验货，有问题就不要点"确认面交"，直接取消订单并举报。 |
| 有人骚扰我？ | 隐私设置 → 联系权限限制谁能私聊；必要时加入**黑名单**（双向不可见）+ 举报。 |
| 举报有效吗？ | 所有举报 24 小时内处理，处理结果会在「我的 → 举报记录」展示，并可申诉。 |
| 退出登录后数据还在吗？ | 在。退出后仅可浏览，重新登录即恢复；注销账号前有 15 天冷静期。 |
| 为什么我发不了活动？ | 发布活动/竞赛需要**学号认证**，去「我的 → 认证」提交。 |
