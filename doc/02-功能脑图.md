# 校园综合平台 功能脑图（Mermaid Mindmap）

> 使用方式：可直接粘贴到支持 Mermaid 的编辑器（Typora、VS Code + Mermaid 插件、mermaid.live、语雀、飞书文档等）中查看与修改。

```mermaid
mindmap
  root((校园综合平台))
    登录与验证
      登录方式
        微信一键授权登录
        手机号验证码登录
        游客模式（仅浏览）
      验证体系
        学号/学生证认证（校内认证用户）
        组织者认证（办活动/办竞赛资质）
        认证状态占位展示（审核中/已认证/未通过）
      登录态
        Token 生命周期与自动续期
        多端登录管理
        未登录拦截与引导
    底部导航
      首页
      动态
      消息（未读角标）
      我的
    首页
      全局搜索导航
        搜索历史（本地保留）
          单条删除
          整体清空（需二次确认）
        热门搜索词
        搜索范围：商品/动态/活动/竞赛/用户
        搜索结果筛选与排序
      快捷服务宫格
        二手交易
          发布闲置
          发布求购
          分类浏览
        找搭子
          学习/运动/娱乐/饭搭子
          发布组队需求
        活动
          活动广场
          我要办活动（认证用户）
        竞赛
          竞赛列表与筛选
          我要办竞赛（认证用户）
        更多服务（预留扩展位）
      个性化推荐流
        按所选专业初始化画像
        按浏览行为实时修正
        按收藏/点赞加权
        冷启动兜底：热门+新发内容
    动态页
      顶部分页导航
        推荐
        关注
        活动
        竞赛
        校园
      混合信息流
        动态卡片（图文/点赞评论）
        竞赛卡片（截止倒计时）
        活动卡片（报名状态）
        个人主页卡片（推荐关注）
        商品卡片（价格/成色）
        校园卡片（通知/资讯）
        交互：下拉刷新/上拉加载/骨架屏
      发布动态
        类型选择（图文/求助/组队）
        话题标签绑定
        图片上传（数量与大小校验）
        内容治理
          敏感词机器过滤
          人工复审（先审后发）
          违规处罚：删除/禁言/封禁
          举报入口
        草稿自动保存
    消息页
      接收通知
        活动通知（报名成功/变更/提醒）
        竞赛通知（截止提醒/审核结果）
        交易通知（售出/下单/面交确认）
        搭子匹配通知（匹配成功/组队邀请）
        互动通知（点赞/评论/关注）
        系统公告
      发起触达
        私信会话（文字/图片）
        活动群聊（组局场景）
        系统自动消息推送
      消息管理
        分类收纳（互动/系统/交易）
        未读角标与已读同步
        消息免打扰设置
    个人主页
      基础信息
        头像/昵称/专业/年级
        认证状态占位标识
      商品订单
        我买到的（买家视角）
        我卖出的（卖家视角）
        订单状态时间线
        面交双向确认
      我的收藏
        商品收藏
        动态收藏
        活动/竞赛收藏（截止提醒联动）
      我参与的活动与竞赛
        已报名列表与状态
        往期参与记录（成长档案）
      我的管理
        我发布的（动态/商品/活动/竞赛）
        下架/编辑/删除
        数据查看（浏览/收藏量）
      设置中心
        账号安全（改绑手机/密码）
        隐私设置（距离/活跃时间/动态可见范围）
        消息通知设置
        通用（缓存清理/深色模式）
        帮助与反馈
        退出登录
    权限规则
      游客（未登录）
        仅浏览：信息流/搜索/详情
        不可发布/不可交易/不可报名
        操作时触发登录引导
      普通用户（已登录未认证）
        发布动态与二手交易
        报名活动/竞赛、找搭子
        不可办活动/办竞赛
      认证用户
        可办活动并管理（报名审核/签到/通知）
        可办竞赛并管理（发布/审核/结果公示）
        发布内容加权曝光
      组织者/管理员侧
        内容审核与举报处理
        用户封禁与信用分管理
    全局交互
      返回规则
        详情页返回保留列表位置
        发布流程返回弹确认（防误触丢失）
        底部 Tab 首页双击回顶
      加载态
        骨架屏（首屏）
        上拉分页加载
        空状态引导（去发布/去逛逛）
        失败重试
      草稿安全治理
        自动保存（本地 + 云端双写）
        意外退出恢复提示
        敏感内容退出前拦截提醒
```

## 补充说明（脑图未展开的规则细节）

| 模块 | 规则要点 |
|---|---|
| 游客权限 | 详情可看，任何"写操作"（发布/报名/收藏/私聊）统一触发登录浮层 |
| 认证用户判定 | 学号认证通过后权限自动升级，认证失败保留普通用户权限并提示原因 |
| 推荐冷启动 | 首次登录仅凭"专业"标签；产生 ≥10 次浏览后切换为行为驱动推荐 |
| 草稿 | 发布类页面（动态/商品/活动/竞赛/搭子）统一接入草稿机制，按类型独立存储 |
| 内容治理 | 机器过滤（命中敏感词直接拦截）→ 人工复审（疑似违规）→ 处罚与申诉闭环 |
