# 16 · 部署手册

> **文档编号**：16 ｜ **版本**：v1.0 ｜ **日期**：2026-09-29 ｜ **状态**：评审稿
> **适用**：dev / test / prod 三环境；负责人 BE-D（兼运维）；操作前阅读《18》§4 数据安全基线

---

## 1. 环境规划

| 环境 | 用途 | 硬件 | 说明 |
|---|---|---|---|
| dev | 开发联调 | 本地 / 1 台 2C4G | Docker Compose 一键起 |
| test | 测试与联调验收 | 1 台 4C8G | 每日 0 点重置种子数据 |
| prod（试点） | 生产 | 2 台 4C8G 云主机（app + db 分离）+ COS | 单校试点规模（NFR-05） |

**软件版本**（与《11》§1 一致，禁止私自升级）：

JDK 17（temurin）· Spring Boot 3.2.x · MySQL 8.0.36 · Redis 7.2 · Nginx 1.24 · Node 18（仅 CI 构建小程序用）· Prometheus 2.5x + Grafana 10

## 2. 基础环境初始化（每台 prod 主机）

```bash
# 1. 系统基线（CentOS/Ubuntu 通用说明）
sudo useradd -m campus && sudo timedatectl set-timezone Asia/Shanghai
sudo yum install -y java-17-openjdk-devel mysql nginx   # Ubuntu: apt 等价
# 2. MySQL 8.0 关键参数（my.cnf）
[mysqld]
character-set-server = utf8mb4
innodb_buffer_pool_size = 4G          # db 机按 60% 内存
max_connections = 500
slow_query_log = 1; long_query_time = 0.5
# 3. Redis：requirepass <强密码>；bind 127.0.0.1 内网 IP；maxmemory 2gb allkeys-lru
```

**数据库初始化**：`mvn flyway:migrate -Pprod`（Flyway 脚本见《12》§5，V1 基线 + 增量）。

## 3. 应用部署（campus-server）

```bash
# 构建（CI 产出 campus-server.jar + 校验和）
mvn clean package -DskipTests
# 部署目录
/opt/campus/{app,logs,backup,cfg}
# systemd（campus-server.service）
[Service]
User=campus
ExecStart=/usr/bin/java -Xms2g -Xmx2g \
  -Dspring.profiles.active=prod \
  -jar /opt/campus/app/campus-server.jar
Restart=always; RestartSec=5
```

配置注入（`application-prod.yml` 最小项，密钥走环境变量不入库）：

```yaml
spring: datasource: url: jdbc:mysql://db内网IP:3306/campus?useSSL=true
redis: host: <rds内网>
cos: secret-id: ${COS_SID}  secret-key: ${COS_SKEY}  bucket: campus-prod-<appid>
tim: sdk-appid: ${TIM_APPID}  key: ${TIM_KEY}
wx: appid: ${WX_APPID}  secret: ${WX_SECRET}
```

## 4. Nginx（接入层）

```nginx
server {
  listen 443 ssl http2;
  server_name api.campus.example.cn;
  ssl_certificate     /etc/nginx/ssl/fullchain.pem;
  ssl_certificate_key /etc/nginx/ssl/privkey.pem;
  client_max_body_size 12m;              # 单文件 ≤10MB + 余量
  location /api/ {
    limit_req zone=api burst=50 nodelay;  # 全局限流（防 NFR 外冲击）
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header X-Forwarded-For $remote_addr;
  }
}
# limit_req_zone $binary_remote_addr zone=api:10m rate=20r/s;
```

> 小程序合法域名（request/uploadFile/downloadFile）须在微信公众平台白名单：`https://api.campus.example.cn`、COS 域名、IM 域名。

## 5. 微信小程序发布（campus-miniapp）

1. 类目：工具-校园生活（备案号填入）；隐私接口声明：相册（图片）、剪贴板（仅粘贴订单号）；
2. 隐私保护指引（内容与《18》§5 隐私政策一致）线上勾选确认；
3. `npm run build` → 微信开发者工具上传 → 提交审核（审核人 J）；
4. **灰度放量**：10%（W16 周三）→ 50%（周四）→ 100%（周五），配合《14》T4.5；
5. 体验版长期保留（test 后端指向），供联调（见《19》§4.3）。

## 6. 监控与告警

| 项 | 配置 | 告警阈值 |
|---|---|---|
| Prometheus | 抓取 Spring Actuator + node_exporter | — |
| Grafana | 看板：QPS/P95/错误率/DB 连接/JVM/磁盘 | 值班群机器人 |
| 接口错误率 | rate(http_5xx) | > 1% 持续 5min → 电话告警 D |
| 提醒任务 | 定时任务心跳埋点 | 当日 09:30 未执行 → 告警 F |
| 磁盘/COS | 日志磁盘、binlog 空间 | > 80% 告警 |

## 7. 备份与恢复（NFR-13）

| 对象 | 策略 | 保留 |
|---|---|---|
| MySQL | 每日 02:00 全量（mysqldump --single-transaction）+ binlog | 全量 30 天，binlog 7 天 |
| COS | 版本控制 + 生命周期 180 天 | — |
| 配置/证书 | /opt/campus/cfg 每周快照 | 12 份 |

**恢复演练**（每季度，S4 前必做一次）：全量恢复到临时实例 → 校验核心表行数与抽查记录 → 记录 RTO（目标 ≤ 30min，见《16》DoD in 《14》§4 M4）。

## 8. 发布与回滚 SOP

```text
发布：CI 绿 → 生成 tag → 备份当前 jar → 替换 → systemctl restart → 健康检查 /actuator/health
      → 冒烟主链路（5 接口）→ 观察错误率 10min
回滚：cp backup/campus-server.bak app/ → restart → 冒烟（全程 ≤ 5 分钟，任一失败立即回滚）
禁令：禁止绕过 CI 直传 jar；禁止生产执行未经评审的 SQL（须走 D 审批 + audit 记录）
```
